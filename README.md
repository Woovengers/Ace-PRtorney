# 1. 프로젝트 한 줄 소개

우테코 PR 리뷰의 시간 흐름을 추적하고 분석해, 리뷰 패턴을 한눈에 보여주는 서비스

# 2. 프로젝트 사용자는 누구인가요?

* 리뷰어를 선택하기 전, 응답 속도와 주 활동 시간대를 확인하고 싶은 우테코 크루
* 나와 리뷰 리듬이 잘 맞는 리뷰어를 찾고 싶은 우테코 크루
* 자신의 리뷰 응답 패턴과 활동 시간대를 객관적으로 확인하고 싶은 리뷰어
* 미션별, PR별, 트랙별 리뷰 흐름을 한눈에 파악하고 싶은 우테코 참여자
* PR 리뷰 코멘트를 더 몰입감 있게 확인하고 답변하고 싶은 우테코 참여자

# 3. 어떤 목적으로 만들어졌나요?

우테코에서는 PR 기반 코드 리뷰가 활발하게 이루어지지만, 실제 리뷰 흐름은 대부분 감에 의존해 파악해야 했습니다.  
크루는 “이 리뷰어는 보통 언제 활동하지?”, “첫 리뷰까지 얼마나 걸리는 편이지?”를 알기 어려웠고, 리뷰어 역시 “내가 보통 얼마나 빠르게 응답하는지”, “어느 시간대에 가장 자주 활동하는지”를 객관적으로 보기 어려웠습니다.

이 프로젝트는 이런 불편을 해결하기 위해 만들어졌습니다.  
실제 GitHub PR / Review 데이터를 바탕으로 첫 리뷰 시간, 재리뷰 시간, 완료까지 걸린 시간, 활동 시간대, 트랙별 흐름 차이를 시각화해 우테코 참여자들이 리뷰 흐름을 더 쉽게 이해하고, 자신에게 더 잘 맞는 리뷰어를 선택할 수 있도록 돕습니다.

또한 PR 리뷰 코멘트를 역전재판 스타일의 법정 공방처럼 보여주고 답변할 수 있는 기능을 제공해, 딱딱한 리뷰 경험을 더 몰입감 있고 재미있는 방식으로 풀어냅니다.

# 4. 기능은 무엇이 있나요?

* 전체 대시보드에서 PR 수, 리뷰 이벤트 수, 저장소 수, 최근 활동 크루/리뷰어 확인
* 크루 상세 분석: 첫 리뷰 대기 시간, 변경 요청 후 응답 시간, PR 완료 시간, 활동 시간대 확인
* 리뷰어 상세 분석: 첫 리뷰 속도, 크루 응답 후 재리뷰 속도, 활동 시간대, 리뷰 이력 확인
* 미션별 분석: 저장소 단위로 PR 규모, 리뷰 밀도, 참여 인원 비교
* PR 드릴다운: 개별 PR의 리뷰 흐름과 타임라인 확인
* 트랙 비교: BE / FE / AN 트랙별 리뷰 규모와 응답 패턴 비교
* 리뷰어 매칭: 크루의 활동 시간대와 잘 맞는 같은 트랙 리뷰어 추천
* 후보 리뷰어 비교: 여러 리뷰어 후보를 같은 기준으로 직접 비교
* PR 리뷰 재판: GitHub PR 리뷰 코멘트를 역전재판 스타일로 확인하고, 코멘트에 답변하거나 새 리뷰 코멘트를 작성

# 5. 다른 서비스와 차별화되는 강점은 무엇인가요?

1. 감이 아니라 실제 리뷰 데이터로 리뷰 흐름을 보여줍니다.  

우테코 코드 리뷰는 보통 “이 리뷰어는 빠른 편인 것 같아”, “이 시간대에 활동하는 것 같아”처럼 경험에 의존해 판단하는 경우가 많습니다. 이 서비스는 실제 GitHub PR / Review 데이터를 바탕으로 첫 리뷰 시간, 재리뷰 시간, 활동 시간대를 분석해 객관적인 기준을 제공합니다.

1. 단순 통계 조회를 넘어 리뷰어 추천까지 연결됩니다.  

일반적인 데이터 시각화 서비스는 현황을 보여주는 데 그치지만, 이 서비스는 크루의 활동 시간대와 리뷰어의 응답 패턴을 비교해 더 잘 맞는 리뷰어를 추천합니다. 데이터를 보여주는 데서 끝나지 않고 실제 리뷰어 선택 의사결정까지 돕습니다.

1. 우테코 코드 리뷰 맥락에 맞춘 리뷰 리듬 분석에 집중했습니다.  

일반적인 GitHub 분석 도구는 커밋 수, 이슈 수 같은 범용 지표 중심인 경우가 많습니다. 반면 이 서비스는 우테코 코드 리뷰에서 중요한 첫 리뷰까지 걸리는 시간, 크루 응답 후 재리뷰 시간, 완료까지의 사이클처럼 리뷰 흐름 자체를 이해하는 지표에 집중했습니다.

1. 사람, 미션, PR, 트랙 단위로 리뷰 흐름을 입체적으로 볼 수 있습니다.  

특정 사람의 성향만 보는 것이 아니라, 어떤 미션에서 리뷰가 오래 걸리는지, 어떤 PR이 여러 차례 리뷰를 거쳤는지, 트랙별로 어떤 차이가 있는지까지 함께 볼 수 있습니다. 개인 분석을 넘어 우테코 전체 리뷰 흐름을 폭넓게 이해할 수 있습니다.

1. 활동 시간대를 시각화해 리뷰 협업의 효율을 높입니다.  

단순 평균 시간만 보여주는 것이 아니라 언제 주로 활동하는지도 함께 보여주기 때문에, 리뷰 요청 타이밍이나 응답 패턴을 더 현실적으로 파악할 수 있습니다. 이는 리뷰 속도뿐 아니라 협업 스트레스를 줄이는 데도 도움이 됩니다.

1. 리뷰 코멘트를 역전재판 스타일로 풀어내는 독특한 경험을 제공합니다.  

PR 리뷰 코멘트를 단순 텍스트 목록으로 보여주는 대신, 법정 공방처럼 구성해 리뷰어의 지적과 크루의 답변을 더 몰입감 있게 확인할 수 있습니다. 실제 GitHub 코멘트에 답변하거나 새 코멘트를 남길 수 있어 재미있는 표현 방식과 실용적인 리뷰 액션이 연결됩니다.

1. 대규모 실제 데이터를 기반으로 해 신뢰도가 높습니다.  

78개 저장소, 19,295개 PR, 219,865개 리뷰 이벤트를 기반으로 분석하기 때문에 일부 사례가 아니라 실제 우테코 리뷰 문화 전반에서 나타나는 흐름을 반영할 수 있습니다. 해커톤 프로젝트라도 데이터 규모와 근거 면에서 강한 설득력을 가질 수 있습니다.
